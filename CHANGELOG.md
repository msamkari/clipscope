# Changelog

## 0.1.0 (2026-11-14)
- First release: one skill and one standard-library Python script. Download a public video with yt-dlp (720p at most, config ignored, URL after `--`) or read a local file; frames and audio with ffmpeg; optional local transcript with whisper; optional loudness and silence metrics.
- Installs nothing, bundles nothing, no login, cookies or keys. 5 tests.
